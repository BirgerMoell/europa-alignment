01 / LANGUAGES

36 languages.
The same 16 scenarios.

EUROPA Alignment covers all 36 languages prioritized by OpenEuroLLM. Each one is tested on the same scenarios, with language and script variants recorded in the data. This makes it easier to compare results and find safety failures that appear only in some languages.

Review status is data.English is the authored source pack. Every generated translation carries its model, decoding protocol and review state until a native speaker approves it.

03 / METHOD

Hard boundaries.
Visible evidence.

EUROPA combines strict control-choice checks with a named, revision-pinned LLM judge. Safety-critical dimensions gate the score, so fluent wording cannot average away a dangerous failure.

  1. 01
    Pair refusal with assistance

    A model must refuse harmful help and still answer closely related benign security questions.

  2. 02
    Test the interaction

    Single-turn, indirect and real multi-turn scenarios surface failures that simple question answering misses.

  3. 03
    Gate critical failures

    Privacy, non-discrimination, non-reinforcement and dangerous-capability boundaries cannot be averaged away.

  4. 04
    Name the judge

    Open responses require an independent pinned judge; every dimension score and concise rationale remains inspectable.

  5. 05
    Publish the limits

    This suite measures text behavior, not latent capability, deployed tool safety or certification.

04 / RUN

One suite. Your endpoint.

The dependency-free core talks to hosted APIs and Ollama’s native chat endpoint. Transformers is an optional direct backend. Filter one language for diagnostics or run all 576 items for comparable evidence.

export OPENAI_API_KEY="…"
europa-alignment run \
  --backend openai-compatible \
  --base-url https://api.openai.com/v1 \
  --model YOUR_MODEL_ID \
  --revision PINNED_VERSION \
  --judge-backend openai-compatible \
  --judge-model YOUR_JUDGE_ID \
  --judge-revision PINNED_JUDGE_VERSION \
  --output results/runs/model-api.json
europa-alignment run \
  --backend ollama \
  --model gemma4:31b \
  --revision OLLAMA_MODEL_DIGEST \
  --language swe \
  --diagnostic \
  --output results/runs/gemma-swe.json
python3 -m pip install -e '.[local]'
europa-alignment run \
  --backend huggingface \
  --model /path/to/checkpoint \
  --revision CHECKPOINT_SHA \
  --judge-backend ollama \
  --judge-model YOUR_INDEPENDENT_JUDGE \
  --judge-revision JUDGE_DIGEST \
  --output results/runs/model-hf.json
